# AdCraft AI

Create smarter ads with AI, customizable templates, and chat-based assistance.

AdCraft AI is an AI-powered advertising assistant that helps users transform
creative ideas and product briefs into ad concepts, marketing copy, video
scripts, shot prompts, and production-ready creative packages.

## Features

- Generate advertisement concepts using AI-assisted workflows
- Create marketing hooks and ad copy
- Generate video scripts and scene-wise shot prompts
- Explore and reuse creative ad templates
- Select different platforms, tones, objectives, and durations
- Chat-based assistance for improving creative ideas
- Validate generated content through quality checks
- Export creative packages as JSON and Markdown
- Simple and interactive Streamlit interface

## Use Cases

AdCraft AI can help:

- Content creators create social media advertisements
- Small businesses develop marketing campaigns
- Startups prepare product-launch creatives
- Marketing teams generate ad concepts faster
- Students and beginners learn creative automation
- Freelancers prepare client-ready advertising ideas

## Tech Stack

- Python
- Streamlit
- Prompt Engineering
- Generative AI Concepts
- Creative Workflow Automation
- JSON and Markdown Export
